Why the columns collide — and what fixes it

On screen a wide table can scroll sideways, so it never has to fit. A PDF page can't scroll. The export currently keeps the on-screen column grid and divides one fixed page width between all eleven columns — so columns end up narrower than their own headings, and print on top of each other.

Step 1

Measure, then draw

Work out how wide each column actually needs to be before printing anything, instead of splitting the page evenly.

Step 2

Long text leaves the grid

Any column of sentences prints full-width under its row. This one change fixes most tables on its own.

Step 3

Turn the page sideways

If it's still too wide, that table's pages go landscape. Only that table — the rest of the document stays upright.

Nothing is ever dropped, nothing overlaps, no value breaks in half, and nothing prints below 8pt.
